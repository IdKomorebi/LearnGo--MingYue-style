# 更新日志

记录本项目（在 KaTrain 基础上加入“理解 KataGo”的明玥式讲解）的每次更新。最新的在最上面。

## 2026-10-13 · v0.2 讲解标签页与棋盘联动

**新增**
- 独立的“讲解”标签页，和信息、详细、笔记并列；分析和下棋模式默认打开，分析模式默认收起原来的“信息”。
- 棋盘联动：讲解打开时，AI 推荐点画青色圈，死活变差的棋块画红圈、变好的画绿圈。
- 讲解末尾加“在棋盘上看 AI 推荐的变化”链接，点击逐手播放。
- 关键手（目损 ≥ 3 目或妙手）自动加算到 `explain/key_move_visits`（默认 1000），每手只加算一次，避免算得浅讲错。
- 界面文字加入简体、繁体和英文翻译（其他语言暂用英文）。

**改动**
- 讲解不再拼在信息面板里。
- 事实层的棋块变化带上每颗子的坐标，供棋盘高亮。
- 中文路数统一用汉字（“左边七路”）。
- 修复 macOS 打包 CI：原来按上游仓库目录名 `katrain` 写死了拷贝路径，改名后找不到目录。

## 2026-10-13 · v0.1 讲解层原型

**新增**
- `katrain/core/explain/`：讲解层。
  - `facts.py` 事实层：从 KataGo 输出算出目损、胜率变化、判定（好棋/小亏/缓手/疑问手/恶手/败着）、实战在候选里的名次、推荐点和后续变化、AI 第一感（policy）、妙手识别、棋块死活变化、区域地盘变化。
  - `style_mingyue.py` 明玥式模板：标题句、角色视角、AI 当裁判、正解变化、金句收尾；算得浅时自动提示“仅供参考”。
  - `llm.py` 明玥风格提示词和 Claude 调用（默认关闭）。
  - `adapters.py` / `service.py`：接 KaTrain 的 `GameNode`，LLM 版在后台线程生成并缓存在节点上。
- 信息面板的“详细”里新增“讲解”一段；`config.json` 新增 `explain` 配置（`enabled` / `llm` / `model`）。
- 测试：`tests/test_explain.py`（用人机大战第四局 76~80 手的真实 KataGo 输出验证适配器，并与 KaTrain 自己算的目损对照）、`tests/test_explain_basic.py`。
- 工具：`tools/mingyue/`（命令行演示、生成 KataGo 查询、回放引擎、无显示器截图脚本）。
- 文档：`docs/mingyue/方案.md`（架构、风格要素、路线图）和界面截图。

**已知限制**
- 让子棋的初始摆子还没处理；死活判定基于 ownership 均值，对劫和对杀比较粗糙。
- LLM 版尚未用真实 API 实测。
- 演示数据只算了 60 visits（CPU 环境），数字仅用于演示流程。
